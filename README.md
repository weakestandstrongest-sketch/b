# iPhone → Windows ファイル転送

ワンタイムパスワードで、iPhone から Windows へ写真・PDF・その他のファイルを送るための小さなツールです。
Python の標準ライブラリだけで動くので、追加のインストールは必要ありません。

## 使い方

1. Windows に [Python](https://www.python.org/downloads/) をインストールする（3.8 以上）
2. `start.bat` をダブルクリックする（ブラウザが自動で開きます）
   - 初回は Windows ファイアウォールの確認が出るので「**プライベート ネットワーク**」を許可してください
3. ブラウザで「**パスワードを発行**」を押す → 6 桁のパスワードと QR コードが出ます
4. iPhone（Windows と**同じ Wi-Fi**、または Windows を **iPhone のテザリング**に接続）のカメラで QR コードを読み取る
   - QR が使えない場合は、画面に出ている URL を Safari で開いて 6 桁を入力
5. 「タップして選ぶ」→「写真ライブラリ」または「ファイルを選択」で選んで「送信」
   → Windows の画面に表示され、`received` フォルダに保存されます

## iPhone のテザリングで使う場合

Wi-Fi がない場所でも、Windows を iPhone のインターネット共有につなげば使えます。
転送は iPhone と Windows の間だけで行われるので、モバイル通信量は使いません。

- テザリングのネットワークは Windows で「**パブリック**」扱いになることが多く、そのままだと iPhone からつながりません。
  設定 → ネットワークとインターネット → 接続中のネットワーク →「**プライベート ネットワーク**」に切り替えてください
- URL は `http://172.20.10.x:8000/send` のような形になります

## 安全のための仕組み

- パスワードは **1 回使うと無効**になります（有効期限は 10 分）
- 5 回間違えるとパスワードは無効になります
- 接続後に送信できるのは 30 分間です。Windows 側の「終了」でいつでも切断できます
- パスワードの発行や、受信した画像の閲覧は **Windows 本体（localhost）からしかできません**

## 設定

環境変数で変更できます。

| 変数 | 既定値 | 内容 |
|---|---|---|
| `PORT` | `8000` | 待ち受けるポート番号 |
| `SAVE_DIR` | `./received` | 画像の保存先 |

## うまくいかないとき

### start.bat を開いても何も起きない / すぐ閉じる
- 黒い画面に出ているメッセージを確認してください（エラー時は止まるようにしています）
- 「Python がインストールされていません」→ 画面の案内どおりにインストールする
- ファイル名が `start.bat.txt` になっていないか確認する（エクスプローラーの「表示」→「ファイル名拡張子」にチェックを入れると確認できます）
- 「WindowsによってPCが保護されました」→「詳細情報」→「実行」

### iPhone で「サーバーが見つかりません」「接続できません」と出る
1. Windows 側で黒い画面が開いたままになっているか確認する（閉じるとサーバーも止まります）
2. iPhone で開いている URL が、黒い画面に表示された `http://数字:8000/send` と同じか確認する
   （`localhost` は iPhone では使えません。数字の方を使ってください）
3. iPhone と Windows が同じ Wi-Fi（またはテザリング）につながっているか確認する
4. Windows のネットワークを「プライベート」にする
   設定 → ネットワークとインターネット → 接続中のネットワークの「プロパティ」→「プライベート ネットワーク」
5. ファイアウォールで Python が許可されているか確認する
   コントロールパネル → Windows Defender ファイアウォール →「Windows Defender ファイアウォールを介したアプリまたは機能を許可」
   →「設定の変更」→ 一覧の「Python」にチェック（「プライベート」に、テザリングで使うなら「パブリック」にも）
   - 以前ファイアウォールの確認画面で「キャンセル」を押していると、ここでチェックが外れています

### その他
- QR コードが出ない → QR の表示にはインターネット接続が必要です。URL を直接入力してください
- HEIC の画像はブラウザ上でサムネイルが出ないことがありますが、ファイルは保存されています
